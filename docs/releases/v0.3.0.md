# opendevops v0.3.0

v0.3.0 adds deployable Slack and scheduler services, clearer approvals and configuration checks,
and operational metrics backed by shared state.

## Highlights

- Run Slack Socket Mode and scheduled jobs with `opendevops slack` and `opendevops scheduler`,
  or enable the corresponding Compose profiles.
- Scheduler maintenance ships in the wheel and creates an atomic PostgreSQL 16 backup before
  pruning idle threads. Failed backups prevent pruning; backup retention is operator-managed.
- Dashboard approvers and administrators can inspect scrubbed, bounded command details while an
  approval is pending. These details do not enter chat transcripts or completed-run APIs.
- `opendevops config check` aggregates configuration failures and warnings; `--live` also probes
  the configured server and remote executors without calling a model provider.
- Prometheus exports policy-denial totals, daily spend and caps, and scheduler success timestamps.
  `/readyz` checks audit storage, the budget counter, Redis, and configured PostgreSQL connectivity.
- Redis deduplicates Alertmanager and GitHub webhook deliveries across workers. Redis failures
  reject webhook processing instead of starting runs without deduplication.

## Upgrade notes

- Service mode now requires `REDIS_URI` or `budgets.daily.redis_url`. The Compose bundle supplies
  Redis; custom service deployments must configure it before upgrading.
- Installed policy packs are enabled. Configure their credential families and trusted executables,
  or remove unused pack files before running `opendevops config check`.
- Slack remains opt-in and requires both Slack tokens and a principal mapping. Scheduler hygiene
  requires a passwordless `OPENDEVOPS_BACKUP_DATABASE_URI`, `PGPASSWORD`, `OPENDEVOPS_BACKUP_DIR`,
  and PostgreSQL 16 `pg_dump`; the Compose scheduler profile supplies the client and backup volume.

## Install

```sh
uv tool install "opendevops[checkpoint,ssh]==0.3.0"
```

For a Compose deployment, download the source-free bundle:

```sh
curl -LO \
  https://github.com/skundu42/opendevops/releases/download/v0.3.0/opendevops-deploy-0.3.0.tar.gz
tar -xzf opendevops-deploy-0.3.0.tar.gz
cd opendevops-0.3.0
cp .env.example .env
docker compose up -d
```

The deployment bundle pins `ghcr.io/skundu42/opendevops:0.3.0` and supports `linux/amd64` and
`linux/arm64`. Existing deployments should retain their secrets, configuration, and persistent
volumes when upgrading.
