# opendevops v0.1.1

This patch release repairs trusted publishing to PyPI by updating the publish action to a
currently available, commit-pinned release. It contains the same application functionality as
v0.1.0 plus the release-pipeline fix and documentation updates merged after that tag.

## Install

```sh
uv tool install "opendevops[checkpoint,ssh]==0.1.1"
```

## Deploy

```sh
curl -fLO \
  https://github.com/skundu42/opendevops/releases/download/v0.1.1/opendevops-deploy-0.1.1.tar.gz
tar -xzf opendevops-deploy-0.1.1.tar.gz
cd opendevops-0.1.1
cp .env.example .env
```

The deployment bundle pins `ghcr.io/skundu42/opendevops:0.1.1` and supports `linux/amd64` and
`linux/arm64`.
