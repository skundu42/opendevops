# opendevops v0.2.0

v0.2.0 hardens the production remote-executor deployment and makes its distributed spend,
authentication, and model-pricing behavior explicit and configurable.

## Highlights

- Adds a shared Redis spent-decision store for remote executor pods, so daily spending decisions
  remain consistent across replicas.
- Supports optional agent-to-executor mTLS and per-environment, per-channel signing keys.
- Adds HashiCorp Vault AppRole and Kubernetes authentication for executor secrets.
- Re-prices context compaction with its own model configuration and resolves message-model keys
  independently, keeping budget caps and daily counters accurate.
- Corrects cloud write-pack documentation to reflect the curated AWS, Google Cloud, and Azure
  write capabilities introduced in v0.1.2.

## Upgrade

```sh
uv tool install "opendevops[checkpoint,ssh]==0.2.0"
```

For a Compose deployment, download the source-free bundle:

```sh
curl -LO \
  https://github.com/skundu42/opendevops/releases/download/v0.2.0/opendevops-deploy-0.2.0.tar.gz
tar -xzf opendevops-deploy-0.2.0.tar.gz
cd opendevops-0.2.0
cp .env.example .env
docker compose up -d
```

The deployment bundle pins `ghcr.io/skundu42/opendevops:0.2.0` and supports `linux/amd64` and
`linux/arm64`.
