# opendevops v0.2.1

v0.2.1 is a release-pipeline patch for v0.2.0.

## Fixed

- Updates PyPI trusted publishing to a metadata-v2.5-compatible action release, allowing the
  project wheel and source distribution to publish through PyPI Trusted Publishing.
- Removes a timing race from the gateway cancellation test used by the release gate.

## Upgrade

```sh
uv tool install "opendevops[checkpoint,ssh]==0.2.1"
```

For a Compose deployment, download the source-free bundle:

```sh
curl -LO \
  https://github.com/skundu42/opendevops/releases/download/v0.2.1/opendevops-deploy-0.2.1.tar.gz
tar -xzf opendevops-deploy-0.2.1.tar.gz
cd opendevops-0.2.1
cp .env.example .env
docker compose up -d
```

The deployment bundle pins `ghcr.io/skundu42/opendevops:0.2.1` and supports `linux/amd64` and
`linux/arm64`.
